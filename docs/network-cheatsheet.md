# Шпаргалка: сеть под HTTP

## От URL до handler

| Этап | Простой вопрос | Пример результата |
|---|---|---|
| URL | куда обращаемся? | `https://api.example.com/tasks` |
| DNS | какой IP у имени? | `203.0.113.10` |
| Transport | как доставляем байты? | TCP для HTTP/1.1 и HTTP/2; QUIC/UDP для HTTP/3 |
| TLS | как защищаем и проверяем узел? | TLS 1.3, сертификат, ALPN |
| HTTP | что просит клиент? | `GET /tasks HTTP/1.1` |
| Go | какая функция обработает запрос? | `ServeMux → handler` |

## Адреса

| Запись | Что означает |
|---|---|
| `localhost` | локальное имя; обычно разрешается в loopback-адрес |
| `127.0.0.1` | IPv4 loopback: только этот компьютер |
| `::1` | IPv6 loopback |
| `0.0.0.0:8080` в `Listen` | слушать порт 8080 на всех локальных IPv4-интерфейсах |
| `:8080` в Go | сокращённый адрес для слушателя; не URL клиента |

## TCP и UDP

| Свойство | TCP | UDP |
|---|---|---|
| Передача | поток байтов | отдельные датаграммы |
| Соединение | есть | классического соединения нет |
| Порядок | восстанавливается | не гарантируется |
| Повторная доставка | есть | нет в самом UDP |
| Границы сообщений | не сохраняются | сохраняются |
| Типичный пример | HTTP/1.1, HTTP/2 | DNS, real-time; QUIC строит над UDP свою надёжность |

## HTTP версии

| Версия | Представление | Параллельность | Транспорт |
|---|---|---|---|
| HTTP/1.0 | текст | обычно новые соединения | TCP |
| HTTP/1.1 | текст | persistent connections; pipelining редко | TCP |
| HTTP/2 | бинарные frames и streams | multiplexing в одном соединении | TCP |
| HTTP/3 | HTTP/2-подобные идеи поверх QUIC | независимые QUIC streams | QUIC поверх UDP |

## TLS

TLS даёт:

- конфиденциальность — посторонний не читает содержимое;
- целостность — изменение данных обнаруживается;
- аутентификацию сервера — клиент проверяет сертификат и имя узла.

TLS не доказывает, что бизнес-ответ правильный, и не заменяет авторизацию пользователя.

## Go API

```go
listener, err := net.Listen("tcp", "127.0.0.1:8081")
conn, err := listener.Accept()

conn, err := net.Dial("tcp", "127.0.0.1:8081")

client := &http.Client{Timeout: 2 * time.Second}
response, err := client.Do(request)
defer response.Body.Close()
```

`http.Client` и `http.Transport` безопасны для конкурентного использования и должны переиспользоваться.
